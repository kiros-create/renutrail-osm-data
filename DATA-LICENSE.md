This is a freely reusable, independently downloadable derivative dataset of
selected OSM infrastructure. Both the generated GeoJSON and index are offered
under ODbL 1.0. Keep this notice, source URL, snapshot time and data license with
redistributions. A consuming map must display OpenStreetMap attribution and
link to the license and downloadable derivative data.

OSM is community mapping. It is not KEPCO's official network, a complete wind
inventory, permitting evidence, operational confirmation, or an assessment of
grid connection feasibility / available capacity. Missing tags are unknown,
not zero. A snapshot's generation date does not make the underlying features
newly verified. Do not infer onshore/offshore solely from location.

The MIT code license does not replace ODbL for data. Synthetic test fixtures
in tests/ are newly created examples, not OSM extracts, and use the MIT license.
